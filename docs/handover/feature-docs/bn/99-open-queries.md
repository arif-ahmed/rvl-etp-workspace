# 99 · ওপেন কোয়ারি

> **Bangla name:** ওপেন কোয়ারি
>
> [← সূচিপত্র](README.md)

এই ডকুমেন্টেশনের প্রতিটি `[UNCONFIRMED: Q-nn]` মার্কার একটি এন্ট্রি এখানে আছে। একটি এন্ট্রি মানে **এই পর্যালোচনায় পাঁচটি রিপোজিটরির কোড থেকে প্রশ্নটির উত্তর নির্ধারণ করা যায়নি** — এটি মানে কোড ভুল, তা নয়। কয়েকটি রিপোজিটরির ফাঁক (কোনো সোর্স ছাড়া একটি বাহ্যিক service), কয়েকটি deployment বা configuration মান, কয়েকটি implementation-এর প্রকৃত অস্পষ্টতা, আর কয়েকটি ক্ষেত্রে এমন কিছু যেখানে কোড স্পষ্ট কিন্তু *উদ্দেশ্য* স্পষ্ট নয়।

কোনো কোয়ারিতে কাজ করার আগে **Kind** কলামটি পড়ুন। চার প্রকার:

| Kind | অর্থ | কে উত্তর দিতে পারে |
|---|---|---|
| **External** | কম্পোনেন্টটি পাঁচটি রিপোজিটরির কোনোটিতেই নেই | BS23 |
| **Deployment** | কোড settings, secrets, SSM বা ক্লাউড থেকে একটি মান পড়ে, যা এই পর্যালোচনায় দেখা যায় না | BS23 / infrastructure |
| **Ambiguity** | কোড পড়া যায়, কিন্তু requirement না জানলে তার সঠিকতা বা উদ্দেশ্য বিচার করা যায় না | BS23 / ব্যবসা |
| **Defect** | কোডটি ভুল বলে মনে হচ্ছে; এটি উত্তর দেওয়ার প্রশ্ন নয়, সংশোধন করার একটি finding | RVL |

অগ্রাধিকার দেওয়ার মতো একমাত্র সারি **Defect** সারি। বাকি সবই ডকুমেন্টেশনের ঋণ।
