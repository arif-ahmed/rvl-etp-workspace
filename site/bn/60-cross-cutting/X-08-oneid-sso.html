X-08 OneID সিঙ্গেল সাইন-অন

Bangla name: OneID সিঙ্গেল সাইন-অন

← 60 · ক্রস-কাটিং · সূচিপত্র · ওপেন কোয়ারি

1. নাম ও উদ্দেশ্য

OneID SSO। একজন গ্রাহক GoBCB পাসওয়ার্ডের বদলে OneID Wallet অ্যাকাউন্ট দিয়ে সাইন ইন করতে পারেন। User Cognito pool-এ OneID বাহ্যিক identity provider হিসেবে oneid নামে কনফিগার করা; ক্লায়েন্ট ওই provider দিয়ে Cognito-র hosted সাইন ইন খোলে এবং সাধারণ User-pool টোকেন পায়। প্রথম OneID লগইনে ক্লায়েন্ট identity API-কে GoBCB প্রোফাইল তৈরি করতে বলে (user/register-sso)। Cognito-তে OneID-এর কনফিগারেশন রিপোজিটরিতে নেই (architecture Q5)।

3. ব্যবসায়িক প্রবাহ

  1. গ্রাহক OneID বাটনে চাপ দেন।
  2. একটি পপআপ (পোর্টাল) বা সিস্টেম ব্রাউজার (অ্যাপ) OneID-এর লগইন পেজ দেখায়; OneID সবসময় credential চায় (prompt=login, পোর্টাল)।
  3. OneID অনুমোদন দেওয়ার পর উইন্ডো বন্ধ হয় এবং গ্রাহক সাইন ইন হয়ে যান।
  4. GoBCB-তে এই ব্যক্তির প্রোফাইল না থাকলে সেটি স্বয়ংক্রিয়ভাবে তৈরি হয়; তারপর গ্রাহক যে পেজ থেকে এসেছিলেন তাতে বা হোমে পৌঁছান।

4. প্রযুক্তিগত প্রবাহ

পোর্টাল (পপআপে ম্যানুয়াল PKCE)

# থেকে → পর্যন্ত হপ কী ঘটে
১ মূল উইন্ডো → পপআপ /:lang/auth/login?sso_init=oneid browser OneID Login নামের ৫০০×৭০০ পপআপ খোলে; sso_login = true সেট করে
২ পপআপ browser একটি PKCE verifier জেনারেট করে (৩২ র‍্যান্ডম বাইট), localStorage.pkce_key হিসেবে সংরক্ষণ করে, S256 challenge হিসাব করে
৩ পপআপ → Cognito hosted UI https://<oauth.domain>/oauth2/authorize?identity_provider=oneid&redirect_uri=…&response_type=…&client_id=…&scope=…&prompt=login&code_challenge=…&code_challenge_method=S256 browser redirect Cognito OneID-এ ফরওয়ার্ড করে
৪ OneID → Cognito → পপআপ redirectSignIn?code=… browser redirect Authorization code
৫ পপআপ → Cognito POST https://<oauth.domain>/oauth2/token fetch, form-encoded grant_type=authorization_code, client_id, code, redirect_uri, code_verifier → id, access, refresh টোকেন
৬ পপআপ browser টোকেনগুলো Amplify-এর localStorage key-তে লেখে (CognitoIdentityServiceProvider.<clientId>.<username>.idToken, …) এবং amplify-signin-with-hostedUI = true; sso_auth_complete = true সেট করে; postMessage({type:'sso-login-success'}); নিজে বন্ধ হয়
৭ মূল উইন্ডো browser প্রতি ৩০০ মিলিসেকেন্ডে পোল করে (এবং message শোনে); Auth.currentAuthenticatedUser({ bypassCache: true })
৮ মূল উইন্ডো → identity GET user/my-profile [HTTP + user token] প্রোফাইল
8a মূল উইন্ডো → identity POST user/register-sso [HTTP + user token] কেবল যখন ধাপ ৮ status_message == "user_not_found" ফেরত দিয়েছে এবং sso_login == true। বডি: Auth.currentAuthenticatedUser() থেকে পাওয়া Amplify ব্যবহারকারী অবজেক্ট। তারপর আবার ধাপ ৮

অ্যাপ (Amplify hosted UI)

# থেকে → পর্যন্ত হপ কী ঘটে
১ অ্যাপ → Cognito hosted UI → OneID Amplify.Auth.signInWithWebUI(provider: AuthProvider.custom('oneid'), isPreferPrivateSession: true) সিস্টেম ব্রাউজার সেশন, private

7. ডেটা ও পার্শ্বপ্রতিক্রিয়া

  • Cognito: প্রথম OneID লগইনে Cognito User pool-এ একটি federated ব্যবহারকারী তৈরি করে (বাহ্যিক provider-এর জন্য Cognito-র আদর্শ আচরণ; অ্যাট্রিবিউট ম্যাপিং রিপোজিটরিতে নেই)।
  • Identity API: register-sso দিয়ে প্রোফাইল তৈরি।
  • পোর্টাল localStorage: pkce_key (বিনিময়ের পর সরানো হয়), Amplify টোকেন key, amplify-signin-with-hostedUI, was_sso_login, sso_login, sso_auth_complete / sso_auth_error।

9. হ্যান্ডওভার নোট

  1. লগআউট OneID সেশন শেষ করে না। পোর্টাল SSO ব্যবহারকারীদের জন্য skipFederatedLogout দিয়ে স্থানীয়ভাবে Cognito থেকে সাইন আউট করে; federatedSignOut() (যা OneID ও Cognito-র লগআউট এন্ডপয়েন্ট কল করত) আছে কিন্তু কখনো কোনো করা হয় না। পোর্টাল পরের লগইনে আবার OneID-কে জিজ্ঞাসা করাতে prompt=login-এর উপর নির্ভর করে।
  2. পোর্টালের register-sso বডি কোনো সংজ্ঞায়িত DTO নয়। এটি Amplify-এর Auth.currentAuthenticatedUser() থেকে ফেরত আসা পুরো অবজেক্ট, Angular-এর HttpClient দিয়ে সিরিয়ালাইজড। identity API বদলানোর আগে DevTools-এ আসল রিকোয়েস্ট দেখুন।
  3. অ্যাপের এরর চাপা পড়ে। loginWithOneID প্রতিটি এরর ধরে শুধু লগ করে; এরপর view model সাইন ইন সফল হয়েছে কি না তা না দেখেই হোমে নেভিগেট করে।
  4. দুটি ভিন্ন নিবন্ধন ট্রিগার। পোর্টাল: কেবল SSO লগইনের সময় user_not_found হলে। অ্যাপ: যেকোনো প্রোফাইল এররে।
  5. পোর্টাল Amplify দুবার কনফিগার করে। পপআপের কলব্যাকে এটি oauth সেকশন সরিয়ে দেয় যাতে Amplify-এর নিজস্ব hosted-UI হ্যান্ডলার কোডটি না নেয় (cognito.service.ts:24-34)। Amplify আপগ্রেড করলে এটি রেখে দিন।
  6. OneID-এর identity-provider সেটআপ ও অ্যাট্রিবিউট ম্যাপিং আর্কিটেকচার ডকুমেন্টে খোলা (Q5)।

11. ডেভেলপার টেস্ট গাইড

লোকাল টেস্টযোগ্যতা: আংশিক (শুধু পোর্টাল)। পোর্টালের প্রক্সি /p/oneid-এ একটি ফেক OneID হোস্ট করে যা স্বয়ংক্রিয়ভাবে অনুমোদন দেয়, PKCE challenge পরীক্ষা করে এবং +8801700000011-এর জন্য আসল Floci টোকেন ফেরত দেয় (docs/user-portal-local.md §5)। আসল OneID ও অ্যাপের প্রবাহ লোকালে চলে না।
